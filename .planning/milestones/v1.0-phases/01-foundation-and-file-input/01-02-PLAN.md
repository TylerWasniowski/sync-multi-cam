1. Create `src/types/index.ts` with the following types:
   ```typescript
   export interface VideoFile {
     id: string;          // unique identifier (crypto.randomUUID())
     file: File;          // the raw File object
     name: string;        // file.name
     size: number;        // file.size in bytes
     type: string;        // file.type MIME string
   }
   ```

2. Create `src/lib/constants.ts` with:
   ```typescript
   export const ACCEPTED_MIME_TYPES = new Set([
     'video/mp4',
     'video/quicktime',      // .mov
     'video/x-matroska',     // .mkv
     'video/webm',
   ]);

   export const ACCEPTED_EXTENSIONS = new Set(['.mp4', '.mov', '.mkv', '.webm']);

   export const MIN_FILES = 2;
   export const MAX_FILES = 4;

   export const FFMPEG_CORE_VERSION = '0.12.10';
   export const FFMPEG_CDN_BASE = 'https://cdn.jsdelivr.net/npm';
   ```

3. Create `src/lib/fileValidation.ts` following the research Pattern 3 (File Validation with MIME Type + Extension Fallback):
   - `getExtension(filename: string): string` -- extracts lowercase extension
   - `isVideoFile(file: File): boolean` -- checks MIME type first, falls back to extension (critical for MKV support per Pitfall 5)
   - `validateFiles(files: File[], currentCount: number, maxFiles: number): { validFiles: File[]; error: string | null }` -- filters to video files, checks count against max, returns clear error messages

   The validation must:
   - Accept files with matching MIME type OR matching extension (not both required)
   - Return a specific error when total would exceed MAX_FILES ("Maximum 4 files allowed. You have X, tried to add Y.")
   - Return a specific error when no valid video files found ("No supported video files found. Accepted formats: MP4, MOV, MKV, WebM.")
   - Silently filter out non-video files when mixed with valid ones (only error if ALL files are invalid)
  </action>

2. Create `src/components/FileDropZone.tsx` following research Pattern 2 (Native File Drop Zone):
   - Props: `onFilesAccepted: (files: File[]) => void`, `currentFileCount: number`, `maxFiles: number`
   - State: `isDragging` (boolean), `error` (string | null)
   - Ref: `dragCounter` (number ref, initialized to 0) to prevent dragLeave flickering (Pitfall 4)
   - Ref: `fileInputRef` for the hidden file input
   - Handlers:
     - `handleDragEnter`: preventDefault, stopPropagation, increment dragCounter, set isDragging true
     - `handleDragLeave`: preventDefault, stopPropagation, decrement dragCounter, set isDragging false only when counter reaches 0
     - `handleDragOver`: preventDefault, stopPropagation (required to allow drop)
     - `handleDrop`: preventDefault, stopPropagation, reset isDragging and dragCounter, extract files from dataTransfer, call validateFiles, either set error or call onFilesAccepted
     - `handleBrowse`: trigger fileInputRef click
     - `handleFileInput`: extract files from input, validate, call onFilesAccepted, reset input value
   - Render: A dashed-border box with conditional styling:
     - Default: `border-gray-600 bg-gray-800/50 hover:border-gray-500`
     - Dragging: `border-blue-500 bg-blue-500/10`
   - Include text "Drag and drop 2-4 video files here" and a "Browse Files" button (`bg-blue-600 hover:bg-blue-500 text-white rounded-lg px-4 py-2`)
   - Show accepted formats hint below the button: "MP4, MOV, MKV, WebM" in `text-gray-500 text-xs`
   - Hidden file input with `accept="video/mp4,video/quicktime,video/x-matroska,video/webm,.mp4,.mov,.mkv,.webm"` and `multiple`
   - Error display: red text (`text-red-400 mt-3 text-sm`) when error state is set
   - File count indicator when currentFileCount > 0: "{currentFileCount} of {maxFiles} files added" in `text-gray-400 text-sm mt-2`
   - When currentFileCount >= maxFiles, hide the drop zone content and show "Maximum files reached" message

3. Create `src/components/FileList.tsx`:
