     - Remove the `if (!(e.ctrlKey || e.metaKey)) return;` guard entirely (line 71).
     - Change the function signature from `React.WheelEvent<HTMLDivElement>` to `WheelEvent` (native DOM type).
     - Keep the zoom logic (factor, SPP clamping, anchor-stable offset) exactly as-is.
     - The handler must call `e.preventDefault()` unconditionally to prevent page scroll when over the waveform.

  2. **Switch from React onWheel to native addEventListener with passive: false:**
     - Remove `onWheel={handleWheel}` from the container div JSX (line 258).
     - Add a `useEffect` that attaches a native wheel listener to `containerRef.current`:
       ```typescript
       useEffect(() => {
         const el = containerRef.current;
         if (!el) return;
         el.addEventListener('wheel', handleWheel, { passive: false });
         return () => el.removeEventListener('wheel', handleWheel);
       }, [handleWheel]);
       ```
     - This is necessary because React's onWheel uses a passive listener, which means `preventDefault()` is silently ignored. The native listener with `{ passive: false }` allows `preventDefault()` to actually work, stopping page scroll when scrolling over the waveform area.

  Note: The handleWheel function references `viewState.samplesPerPixel`, `viewState.scrollOffset`, `maxSamplesPerPixel`, and `onViewStateChange` via closure (useCallback). Keep the useCallback wrapper and its dependency array, but update the type signature and remove the Ctrl guard.

       ctx: CanvasRenderingContext2D,
       duration: number,
       viewState: ViewState,
       sampleRate: number,
       canvasWidth: number,
       canvasHeight: number,
     ): void {
       const endX = (duration * sampleRate - viewState.scrollOffset) / viewState.samplesPerPixel;
       if (endX >= canvasWidth || endX < 0) return; // not visible or fully past
       // Draw dimmed overlay for region beyond audio end
       ctx.fillStyle = TRACK_END_COLOR;
       ctx.fillRect(endX, 0, canvasWidth - endX, canvasHeight);
       // Draw a thin vertical line at the track end boundary
       ctx.strokeStyle = TRACK_END_LINE_COLOR;
       ctx.lineWidth = 1;
       ctx.beginPath();
       ctx.moveTo(endX, 0);
       ctx.lineTo(endX, canvasHeight);
       ctx.stroke();
     }
