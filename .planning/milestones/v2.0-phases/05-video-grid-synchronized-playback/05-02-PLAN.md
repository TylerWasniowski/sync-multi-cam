  <action>
    Implement the data flow from waveform scrub position to VideoTile poster frames. This fulfills the locked user decision: "When the user scrubs on the waveform, the poster frame updates to show the frame at the scrubbed position -- even before full playback is ready."

    **src/lib/posterFrame.ts:**

    Create a poster frame extraction utility following RESEARCH.md Pattern 3.

    Exports:
    ```typescript
    export function extractPosterFrame(
      file: File,
      timeSeconds: number,
    ): Promise<string>; // returns blob URL for the extracted frame

    export function createPosterExtractor(
      file: File,
    ): {
      extract: (timeSeconds: number) => Promise<string>;
      destroy: () => void;
    };
    ```

    Implementation:
    1. `extractPosterFrame(file, timeSeconds)`: One-shot extraction.
       - Create a hidden `<video>` element with `preload="metadata"`, `muted = true`.
       - Set `src = URL.createObjectURL(file)`.
       - Wait for `loadedmetadata` event.
       - Set `currentTime = Math.max(0.001, timeSeconds)` (avoid potential black frame at exactly 0).
       - Wait for `seeked` event.
       - Create an offscreen `<canvas>` with `video.videoWidth` x `video.videoHeight`.
       - Draw the video frame: `ctx.drawImage(video, 0, 0)`.
       - Convert to blob: `canvas.toBlob(callback, 'image/jpeg', 0.85)`.
       - Revoke the video's blob URL (no longer needed).
       - Return `URL.createObjectURL(blob)` -- caller is responsible for revoking this poster URL when replaced or on cleanup.

    2. `createPosterExtractor(file)`: Reusable extractor for repeated scrub operations on the same file.
       - Create ONE hidden `<video>` element and blob URL on construction. Set `preload="metadata"`, `muted = true`.
       - Wait for `loadedmetadata` internally (store a ready promise).
       - `extract(timeSeconds)`: Await ready promise. Set `currentTime`. Wait for `seeked`. Draw to canvas. Return poster blob URL.
       - Handle rapid calls: If `extract()` is called while a previous seek is pending, discard the stale seek result and only process the latest request. Use an incrementing request ID to detect staleness.
       - `destroy()`: Revoke the video blob URL, remove the video element, clean up.

    This reusable extractor avoids creating/destroying a video element on every scrub, which is critical for ~10fps scrub updates.

    **Update src/components/WaveformPanel.tsx:**

    Add an optional `onScrub` callback prop that fires when the user's cursor position changes over the waveform.

    Changes:
    1. Extend `WaveformPanelProps`:

       export interface WaveformPanelProps {

       - When `update.cursorTime !== undefined`, call `props.onScrub?.(update.cursorTime)`.
    3. In `handlePointerLeaveAll`, call `props.onScrub?.(null)` to signal scrub end.
    4. This is a minimal addition -- the existing cursor tracking logic already computes the time from pointer position. We just need to surface it upward via the callback.

    **Update src/components/PlaybackSection.tsx:**

    Wire the scrub-to-poster pipeline. This connects WaveformPanel's `onScrub` to poster frame extraction to VideoGrid's `posterUrls`.

    Changes:
    1. Add state: `posterUrls: (string | null)[]` -- one per result, initialized to all nulls.
    2. Create poster extractors: In a useEffect keyed on `results`, create one `createPosterExtractor(result.originalFile)` per result. Store in a ref. Destroy all on cleanup. On initial creation, extract poster frames at time 0 (or `result.trimSeconds`) for each video to show initial poster frames immediately.
    3. Add `handleScrub(time: number | null)` callback:
       - If `time === null`, do nothing (keep current poster frames visible; don't clear them on pointer leave).
       - Throttle to ~10fps (100ms) using a timestamp check: skip if less than 100ms since last extraction. Use rAF gating (existing project pattern) on top of the throttle.
       - For each result, compute the per-video scrub time: `time + result.trimSeconds` (accounting for sync offset -- the waveform time axis is in "aligned" time, so add each video's trim offset to get the absolute video time).
       - Call `extractor.extract(perVideoTime)` for each extractor.
       - On resolve, revoke the previous poster blob URL for that index, set the new one in `posterUrls` state.
       - Handle stale results: If a newer scrub has fired since this extraction started, discard the result (the extractor's internal staleness check handles most of this).
    4. Pass `onScrub={handleScrub}` to `<WaveformPanel>`.
    5. Pass `posterUrls={posterUrls}` to `<VideoGrid>`.
    6. On cleanup (unmount or results change): revoke all poster blob URLs, destroy all extractors.

    Memory management: Track all poster blob URLs in a ref (e.g., `prevPosterUrlsRef`). Before setting a new poster URL for a given index, revoke the previous one. On component unmount, revoke all remaining URLs.
