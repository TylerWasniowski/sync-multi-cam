    **src/lib/videoSync.ts:**

    Create the leader-follower sync engine following RESEARCH.md Pattern 2.

    Exports:
    ```typescript
    export interface SyncEngine {
      start: () => void;
      stop: () => void;
      seek: (time: number) => void;
      destroy: () => void;
    }

    export function createSyncEngine(
      leader: HTMLVideoElement,
      followers: HTMLVideoElement[],
      offsets: number[],
      onFrame?: (time: number) => void,
    ): SyncEngine;
    ```

    Implementation:
    1. Constants: `DRIFT_THRESHOLD_NUDGE = 0.05` (50ms), `DRIFT_THRESHOLD_SEEK = 0.1` (100ms), `PLAYBACK_RATE_FAST = 1.03`, `PLAYBACK_RATE_SLOW = 0.97`, `PLAYBACK_RATE_NORMAL = 1.0`.
    2. Detect rVFC support: `'requestVideoFrameCallback' in HTMLVideoElement.prototype`.
    3. `syncFollowers(leaderTime)`: For each follower, compute `expectedTime = leaderTime - offsets[i]`. Clamp expectedTime to `[0, follower.duration]`. Read `follower.currentTime`. Compute `drift = actualTime - expectedTime`.
       - `|drift| > DRIFT_THRESHOLD_SEEK`: Hard seek (`follower.currentTime = expectedTime`), reset `playbackRate = 1.0`.
       - `|drift| > DRIFT_THRESHOLD_NUDGE`: Nudge (`playbackRate = drift > 0 ? SLOW : FAST`).
       - Otherwise: Reset `playbackRate = 1.0` (CRITICAL per Pitfall 2 in research).
    4. `onVideoFrame(_now, metadata)`: If active, call `syncFollowers(metadata.mediaTime)`, call `onFrame?.(metadata.mediaTime)`, re-register callback. Use rVFC's `mediaTime` (not `currentTime`) for deterministic frame identification.
    5. `onAnimationFrame()`: If active, call `syncFollowers(leader.currentTime)`, call `onFrame?.(leader.currentTime)`, request next rAF.
    6. `start()`: Set active=true. If rVFC available, register `leader.requestVideoFrameCallback(onVideoFrame)`. Else, start rAF loop.
    7. `stop()`: Set active=false. Cancel any pending rAF. Reset ALL followers' playbackRate to 1.0 (per Pitfall 2).
    8. `seek(time)`: Set `leader.currentTime = time`. For each follower, set `follower.currentTime = time - offsets[i]` (clamp to `[0, duration]`). Reset all playbackRates to 1.0.
    9. `destroy()`: Call stop().

    Offset semantics: The `offsets` array contains each follower's time offset relative to the leader. For this project, use `DownloadableResult.trimSeconds` as the basis. The leader is the video with `trimSeconds = 0` (or the minimum). Other videos' offsets are their `trimSeconds` minus the leader's `trimSeconds`. Since videos were trimmed to align, these offsets should be small (sub-keyframe residuals). If using ORIGINAL files for playback (per RESEARCH.md recommendation), the offset is the `trimSeconds` value directly -- each video starts playing at its `trimSeconds` position to align with the leader.
