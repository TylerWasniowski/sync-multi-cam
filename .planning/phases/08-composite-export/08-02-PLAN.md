  <files>src/lib/exportComposite.ts</files>
  <action>
    Add the `exportComposite()` async function to the existing `src/lib/exportComposite.ts` (which already has types, presets, and `buildExportArgs` from Plan 01).

    The function signature:
    ```typescript
    export async function exportComposite(
      results: DownloadableResult[],
      config: ExportConfig,
      audioConfig: AudioConfig,
      totalDurationSeconds: number,
      onProgress?: (ratio: number) => void,
    ): Promise<Uint8Array>
    ```

    Implementation steps (follow existing videoTrimmer.ts pattern):
    1. Get FFmpeg instance via `getFFmpeg()`
    2. Write input files to MEMFS sequentially:
       - Use `trimmedData` when available (already aligned)
       - Fall back to `new Uint8Array(await result.originalFile.arrayBuffer())` when trimmedData is null
       - Name files `input_0.mp4`, `input_1.mp4`, etc.
    3. Compute grid layout at export resolution: `computeGridLayout(config.width, config.height, results.length, 16/9)`
    4. Build FFmpeg args via `buildExportArgs(layout.tiles, config, results.length, audioConfig)`
    5. Set up progress handler:
       - Progress: `ratio = Math.min(event.time / (totalDurationSeconds * 1_000_000), 1)`
       - Use `ffmpeg.on('progress', handler)` and `ffmpeg.off('progress', handler)` in try/finally
    6. Execute FFmpeg: `await ffmpeg.exec(args)`
    7. Read output: `await ffmpeg.readFile('composite_output.mp4') as Uint8Array`
    8. Clean up in finally block: delete all input files and output file from MEMFS using `ffmpeg.deleteFile(name).catch(() => {})`
    9. Return the output Uint8Array

    For Uint8Array data, use `ffmpeg.writeFile(name, data)` directly. For File objects, convert with `new Uint8Array(await file.arrayBuffer())`.

    Important: the 'preparing' vs 'encoding' state distinction is handled at the UI layer (ExportPanel), not here. This function only reports encoding progress ratio (0 to 1).
  </action>

  <action>
    **ExportPanel.tsx** -- New component with the following UI and behavior:

    Props:
    ```typescript
    interface ExportPanelProps {
      results: DownloadableResult[];
      mutedTracks: MutedTracks;
      totalDurationSeconds: number;
      disabled?: boolean;  // true when videos not ready
    }
    ```

    State:
    - `resolution: ResolutionKey` (default '1080p')
    - `exportState: ExportState` (default 'idle')
    - `progress: number` (0-1 ratio)
    - `errorMessage: string | null`

    UI layout (Tailwind, matches dark theme):
    - Horizontal bar at the bottom of PlaybackSection, below waveforms
    - Left side: Resolution dropdown (`<select>`) with 4K/1080p/720p options
    - Center: Export button ("Export MP4") -- disabled during export or when `disabled` prop is true
    - Right side: conditional based on exportState:
      - `idle`: nothing extra
      - `preparing`: "Preparing..." text with spinner
      - `encoding`: progress bar (Tailwind bg-blue-600 bar inside bg-gray-700 container) with percentage text
      - `complete`: "Download ready" (brief -- auto-downloads so this is transient)
      - `error`: error message in red text with "Retry" button that resets to idle

    Export handler:
    1. Set state to 'preparing'
    2. Derive AudioConfig from mutedTracks:
       - If ALL tracks are muted (mutedTracks.size === results.length): `{ mode: 'none' }`
       - Otherwise: `{ mode: 'mix', trackIndices: [indices where !mutedTracks.has(i)] }`
       - The "mix" mode handles both single and multiple unmuted tracks (buildAudioArgs already optimizes single-track mix to direct map)
    3. Build ExportConfig from selected resolution: `{ ...EXPORT_RESOLUTIONS[resolution], fps: 30, crf: 23 }`
    4. Set state to 'encoding'
    5. Call `exportComposite(results, config, audioConfig, totalDurationSeconds, (ratio) => setProgress(ratio))`
    6. On success: trigger download via `triggerDownload(data, 'composite.mp4', 'video/mp4')`, set state to 'complete', then after 2s reset to 'idle'
    7. On error: set state to 'error', set errorMessage to error.message

    Style the select and button to match existing TransportBar styling (bg-gray-700, text-gray-300, rounded, text-xs/text-sm).

    **PlaybackSection.tsx** -- Wire ExportPanel:
    1. Import ExportPanel
    2. Add `<ExportPanel>` after the `<WaveformPanel>` JSX, inside the playback section container div
    3. Pass props: `results={results}`, `mutedTracks={mutedTracks}`, `totalDurationSeconds={duration}`, `disabled={!allVideosReady}`
