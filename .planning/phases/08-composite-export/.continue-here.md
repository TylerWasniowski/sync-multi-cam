Phase 8 WebCodecs export rework: Plan 08-01 complete, Plan 08-02 Task 1 committed. Task 2 is the human-verify checkpoint. Two bugs have been fixed this session but the test infrastructure isn't fully working yet.

Bug 1 (FIXED): Mediabunny `Input` only accepted `[MP4]` format — MOV files (QuickTime container with 'qt  ' major brand) were rejected. Fixed by adding `QTFF`, `MATROSKA`, `WEBM` to the formats array. Test videos are `.MOV` (iPhone) and `.mp4` (Pixel), confirming the MOV format was the demux error cause.

Bug 2 (FIXED): `AudioBuffer is not defined` in Web Worker. Web Audio API (`AudioBuffer`, `OfflineAudioContext`) isn't available in Worker contexts in all browsers. Rewrote the entire audio pipeline to use mediabunny's `AudioSampleSink` + `AudioSampleSource` + `AudioSample` which use WebCodecs `AudioData` (available in Workers). Includes raw PCM mixing with linear interpolation resampling for multi-track support.

Test infrastructure (IN PROGRESS): Installed Playwright + created test harness (`test-export.html` + `src/test-export-harness.ts`) that creates small WebM test videos via MediaRecorder and exercises the full export pipeline. The Playwright test connects to Edge via CDP. **Blocker**: WSL2 networking prevents connecting to Windows Edge's CDP port — WSL2 localhost != Windows localhost. Need to either install Linux Chromium deps (needs sudo) or find a working CDP bridge.
