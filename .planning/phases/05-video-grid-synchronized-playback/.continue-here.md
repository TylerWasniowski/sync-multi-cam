<context>
The root cause of "videos never play" was React StrictMode revoking the blob URL. useMemo cached the URL across StrictMode's unmount/remount, but the useEffect cleanup revoked it in between. The second mount reused the stale revoked URL. Moving URL creation to useEffect ensures each StrictMode cycle creates a fresh valid URL.

The sync engine offset bug would have caused followers to seek backwards (leaderTime - positive_offset = wrong position). Fixed to leaderTime + offset.

The hover-scrub issue was WaveformPanel calling onScrub on every pointer move (even without click). This triggered poster frame extraction at ~10fps per file, starving the browser's video decoder so the main video elements never reached canplay.
</context>
