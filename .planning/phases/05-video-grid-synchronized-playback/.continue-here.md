<remaining_work>

**3 bugs to fix (from UAT Test 1):**

1. **Videos never play (blocker):** The `videoRef` prop uses `React.RefObject` which may not be assignable in the VideoTile/VideoGrid ref-forwarding pattern. The ref chain: `PlaybackSection.videoRefs` → `VideoGrid.tileRefs` → `VideoTile.videoRef` — need to verify refs are actually populated so the sync engine can find `<video>` elements. Check `handlePlay` in PlaybackSection — it iterates `videoRefs.current` which may be all null.

2. **Fill/letterbox don't fill the whole frame:** `computeGridLayout` constrains tile dimensions by aspect ratio, leaving blank space around tiles. The tiles should fill their grid cells fully (using the full cell width/height), and let `object-fit: cover/contain` on the `<video>` element handle cropping vs letterboxing. Currently the algorithm computes tiles smaller than cells to preserve aspect ratio — that's wrong for the CSS approach.

3. **3rd tile not centered (odd counts):** With 3 tiles in a 2-col layout, tile 3 sits at col 0 row 1 — left-aligned. The last row should be centered when it has fewer tiles than columns. Fix in `computeGridLayout`: detect incomplete last row and add extra X offset to center those tiles.

**After fixes:** User requested we create visual tests with different video counts to verify the grid looks right before continuing.
