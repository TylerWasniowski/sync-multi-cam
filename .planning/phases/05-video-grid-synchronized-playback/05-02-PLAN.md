  <action>
    Create a VideoTile component that renders a single video element with poster frame and loading state.

    Props interface:
    ```typescript
    interface VideoTileProps {
      file: File;
      displayMode: DisplayMode;
      style: React.CSSProperties; // absolute positioning from layout algorithm
      videoRef: React.RefObject<HTMLVideoElement | null>;
      onReady: () => void; // called when video can play
    }
    ```

    Implementation:
    1. Create a blob URL from `file` using `URL.createObjectURL()` in a useEffect. Revoke on cleanup.
    2. Set the blob URL as the `<video>` element's `src`.
    3. Video attributes: `preload="auto"`, `muted` (audio handled separately in Phase 6), `playsInline`.
    4. Track loading state with a `loading` boolean (starts true).
    5. Listen for `canplay` event on the video element. When fired, set `loading = false` and call `onReady()`.
    6. Also check `video.readyState >= HTMLMediaElement.HAVE_ENOUGH_DATA` on mount in case the video is already ready.
    7. Apply `object-fit: cover` when displayMode is 'fill', `object-fit: contain` when 'letterbox'.
    8. Set `backgroundColor: '#000'` on the video element for letterbox black bars.
    9. When loading is true, show a spinner overlay: absolute positioned div with `bg-black/50` backdrop and a CSS spin animation (Tailwind `animate-spin` on a border-based circle).
    10. The outer div uses `position: absolute` with `overflow: hidden` from the style prop.

    Styling: Follow project dark theme (bg-gray-900 family). No gap/margin on the tile itself -- tiles touch edge-to-edge per user decision.

    Important: Do NOT revoke the blob URL while the video element is still mounted. Only revoke in the useEffect cleanup (unmount).
