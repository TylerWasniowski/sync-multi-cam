  <behavior>
    - computeGridLayout(800, 600, 1, 16/9) returns 1 tile centered, filling the width at 16:9 ratio
    - computeGridLayout(800, 600, 2, 16/9) returns 2 tiles side-by-side (2 cols x 1 row)
    - computeGridLayout(800, 600, 4, 16/9) returns 4 tiles in a 2x2 grid
    - computeGridLayout(800, 600, 3, 16/9) returns 3 tiles -- 2 cols x 2 rows (last slot empty), or 3 cols x 1 row -- whichever maximizes tile area
    - computeGridLayout(800, 600, 6, 16/9) returns 6 tiles in optimal arrangement (3x2 or 2x3, whichever maximizes area)
    - All tile positions are non-negative integers (Math.round applied)
    - All tiles have identical width and height within a given layout
    - Tiles do not overlap (no x/y/w/h collision)
    - Tiles fit within container bounds (x + width <= containerWidth, y + height <= containerHeight)
    - Grid is centered: offset from container edges is symmetric horizontally and vertically
    - For 0 tiles, returns empty tiles array with 0 dimensions
    - For containerWidth or containerHeight of 0, returns tiles with 0 dimensions
  </behavior>
  <implementation>
    Implement `computeGridLayout()` in src/lib/gridLayout.ts following the brute-force column iteration pattern from RESEARCH.md Pattern 1:

    1. Iterate column counts from 1 to tileCount
    2. For each column count, compute rows = ceil(tileCount / cols)
    3. Compute max tile size that fits container while maintaining aspect ratio
    4. Pick the configuration that maximizes total tile area
    5. Generate absolute pixel positions, centered in the container
    6. Round all coordinates to integers (Math.round)

    Edge cases:
    - tileCount = 0: return empty layout
    - containerWidth or containerHeight = 0: return tiles with 0 dimensions
    - tileCount = 1: single tile centered

    Also add `DisplayMode` type to src/types/index.ts:

  </implementation>
