**Playhead Follow Mode (auto-scroll during playback):**

Add a ref to track whether the user is actively interacting (pan or scrub):
```typescript
const userInteractingRef = useRef(false);
```

Set `userInteractingRef.current = true` when `panelModeRef.current` changes to 'pan' or 'scrub' (in handlePanelPointerDown), and `false` in handlePanelPointerUp. Similarly, when WaveformTrack signals scrubStart/scrubEnd, the panel should set this flag. The simplest approach: set to `true` in `onScrubStart` wrapper, `false` in `onScrubEnd` wrapper.

Add a `useEffect` that watches `playheadTime` and `isPlaying`:
```typescript
useEffect(() => {
  if (!isPlaying || playheadTime == null || userInteractingRef.current) return;

  const playheadSample = playheadTime * sampleRate;
  const viewStart = viewState.scrollOffset;
  const viewEnd = viewState.scrollOffset + canvasWidth * viewState.samplesPerPixel;

  // If playhead is outside visible viewport, page-turn forward
  if (playheadSample < viewStart || playheadSample > viewEnd) {
    // Page turn: place playhead at ~10% from left edge (not centered, to show upcoming content)
    const newOffset = playheadSample - canvasWidth * viewState.samplesPerPixel * 0.1;
    handleViewStateChange({ scrollOffset: Math.max(0, newOffset) });
  }
}, [playheadTime, isPlaying, sampleRate, viewState.scrollOffset, viewState.samplesPerPixel, canvasWidth, handleViewStateChange]);
```

**IMPORTANT:** Use "page turn" approach per Pitfall 5 in research -- when the playhead exits the viewport, jump forward so the playhead is near the left edge. Do NOT smoothly scroll or center on every frame (that causes visual jumping/jank). The playhead only triggers a scroll when it leaves the viewport, then the view stays stable until the playhead exits again.

**Playhead-Anchored Zoom During Playback:**

Modify the existing `handleWheel` callback. Currently it anchors zoom at the pointer's pixel position. Change to:

1. If `isPlaying` is true AND `playheadTime` is not null, anchor zoom on the playhead position instead of the pointer:
   ```typescript
   // In handleWheel, after computing newSPP:
   let anchorSample: number;
   if (isPlaying && playheadTime != null) {
     // Anchor zoom on playhead during playback
     anchorSample = playheadTime * sampleRate;
     // Compute pixel position of playhead for offset calculation
     const playheadPixel = (anchorSample - viewState.scrollOffset) / viewState.samplesPerPixel;
     const clampedPlayheadX = Math.max(0, Math.min(playheadPixel, canvasWidth));
     const newOffset = anchorSample - clampedPlayheadX * newSPP;
     handleViewStateChange({
       samplesPerPixel: newSPP,
       scrollOffset: Math.max(0, newOffset),
     });
   } else {
     // Original pointer-anchored zoom (existing logic, unchanged)
     const cursorSample = viewState.scrollOffset + clampedX * oldSPP;
     const newOffset = cursorSample - clampedX * newSPP;
     handleViewStateChange({
       samplesPerPixel: newSPP,
       scrollOffset: Math.max(0, newOffset),
     });
   }
   ```

2. Add `isPlaying` and `playheadTime` to the `handleWheel` dependency array.

**Edge case: zooming during scrub.** When scrubbing (`userInteractingRef.current === true`), use pointer-anchored zoom (existing behavior), not playhead-anchored. The playhead IS at the pointer during scrub, so either anchor would work, but pointer-anchor is more predictable if the user pauses scrub and zooms.

The conditional becomes: `if (isPlaying && playheadTime != null && !userInteractingRef.current)`.
