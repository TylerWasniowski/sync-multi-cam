<task type="auto">
  <name>Task 1: Scaffold Vite project with all Phase 1 dependencies and COOP/COEP configuration</name>
  <files>package.json, vite.config.ts, tsconfig.json, tsconfig.app.json, tsconfig.node.json, src/main.tsx, src/App.tsx, src/index.css, public/_headers, index.html, .gitignore</files>
  <action>
1. Scaffold a new Vite project in the current directory using `npm create vite@latest . -- --template react-ts`. This creates the full React + TypeScript scaffold including tsconfig files, ESLint, and a basic App component.

2. Install core dependencies:
   ```
   npm install @ffmpeg/ffmpeg @ffmpeg/util
   npm install tailwindcss @tailwindcss/vite
   ```

3. Replace `vite.config.ts` with the following configuration (from research Pattern: Vite Configuration for FFmpeg WASM):
   - Import and add `react()` plugin (already scaffolded)
   - Import and add `tailwindcss()` plugin from `@tailwindcss/vite`
   - Add `optimizeDeps: { exclude: ['@ffmpeg/ffmpeg', '@ffmpeg/util'] }` to prevent esbuild WASM errors
   - Add `server.headers` with `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp`

4. Replace `src/index.css` content with just `@import "tailwindcss";` (Tailwind v4 entry point -- no config file needed).

5. Create `public/_headers` file for Cloudflare Pages:
   ```
   /*
     Cross-Origin-Opener-Policy: same-origin
     Cross-Origin-Embedder-Policy: require-corp
   ```
   This file must be in `public/` so Vite copies it to `dist/` during build.

6. Replace `src/App.tsx` with a minimal placeholder that uses Tailwind dark theme classes to prove styling works:
   ```tsx
   function App() {
     return (
       <div className="min-h-screen bg-gray-950 text-gray-100 flex items-center justify-center">
         <h1 className="text-2xl font-semibold">Sync Multi-Cam</h1>
       </div>
     );
   }
   export default App;
   ```

7. Ensure `src/main.tsx` imports `./index.css` (should be scaffolded by default).

8. Verify the dev server starts: `npm run dev`. Verify Tailwind classes are applied (dark background, light text visible). Verify in the browser console that `crossOriginIsolated === true` on the dev server.

9. Run `npm run build` and verify `dist/_headers` exists in the build output.
  </action>
  <verify>
    <automated>npm run build && test -f dist/_headers && echo "PASS: _headers in dist" || echo "FAIL: _headers missing from dist"</automated>
  </verify>
  <done>Vite project scaffolded with React 19, TypeScript, Tailwind CSS v4, FFmpeg WASM packages installed, COOP/COEP headers configured for both dev (vite.config.ts) and production (public/_headers), build succeeds and dist/_headers exists.</done>
</task>

<task type="auto">
  <name>Task 2: Deploy skeleton to Cloudflare Pages and validate cross-origin isolation</name>
  <files>package.json</files>
  <action>
1. Build the project: `npm run build`

2. Deploy to Cloudflare Pages using wrangler CLI:
   ```
   npx wrangler pages deploy dist --project-name=sync-multi-cam
   ```
   If this is the first deployment, wrangler will create the project. Follow any prompts for Cloudflare account authentication.

   Note: If wrangler authentication fails, this becomes a checkpoint:human-action. The executor should attempt CLI auth first (`npx wrangler login`) and only escalate to the user if that fails.

3. After deployment, note the deployment URL (e.g., `https://sync-multi-cam.pages.dev` or a unique preview URL).

4. Add a `deploy` script to package.json for convenience:
   ```json
   "scripts": {
     "deploy": "npm run build && npx wrangler pages deploy dist --project-name=sync-multi-cam"
   }
   ```

5. Validate the deployment by documenting the verification steps. The critical check is that the COOP/COEP headers are present on the deployed site:
   - Response headers should include `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp`
   - `crossOriginIsolated` should be `true` in the browser console

6. If headers are NOT present: check that `dist/_headers` exists and has correct content. Check Cloudflare Pages documentation for any format issues. This is a blocking issue that must be resolved before proceeding.
