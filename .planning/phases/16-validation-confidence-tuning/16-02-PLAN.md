<!-- Confidence formula in fftEngine.ts (may need tuning) -->
From src/lib/fftEngine.ts (computeConfidence function):
```typescript
// Factor 1: Peak strength
// Maps peak value from [0.6, 1.0] to [0, 1]. Values below 0.6 are noise-level.
const peakStrength = Math.min(1, Math.max(0, (peakValue - 0.6) / 0.4));

// Factor 2: Peak uniqueness
const peakUniqueness = secondPeak < EPSILON ? 1.0 : 1.0 - secondPeak / peakValue;

const raw = peakStrength * peakUniqueness * 100;
return Math.round(Math.min(100, Math.max(0, raw)));
```

Tuning knobs:
- `0.6` threshold: Lower bound for peak strength (if real-world peaks are below 0.6, all confidence = 0)
- `0.4` range: Maps [0.6, 1.0] to [0, 1]
- NEIGHBORHOOD_RADIUS = 50: Exclusion zone around main peak for second-peak search

From src/lib/audioSync.ts (confidence level thresholds):
```typescript
export function getConfidenceLevel(confidence: number): 'high' | 'medium' | 'low' {
  if (confidence >= 70) return 'high';
  if (confidence >= 40) return 'medium';
  return 'low';
}
```
