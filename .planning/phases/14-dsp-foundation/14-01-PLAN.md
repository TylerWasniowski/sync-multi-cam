    **Internal (non-exported) helper functions:**

    4. `findPeakParabolic(correlation: Float64Array, searchStart: number, searchEnd: number, fftSize: number): { index: number; value: number }`

       - Handles circular wrap: check indices [0, maxOffsetSamples] for positive offsets AND [fftSize - maxOffsetSamples, fftSize) for negative offsets
       - After finding integer peak index, applies parabolic interpolation:
         ```
         alpha = correlation[peakIndex - 1]
         beta = correlation[peakIndex]       // the peak
         gamma = correlation[peakIndex + 1]
         denominator = alpha - 2 * beta + gamma
         if |denominator| < 1e-10: return peakIndex (flat, no refinement)
         fractional = 0.5 * (alpha - gamma) / denominator
         refinedIndex = peakIndex + fractional
         ```
       - Maps index to offset: if refinedIndex < fftSize/2, offset = +refinedIndex; else offset = refinedIndex - fftSize

    5. `computeConfidence(correlation: Float64Array, peakIndex: number, peakValue: number, searchStart: number, searchEnd: number, fftSize: number): number`
       - Per D-06: `confidence = clamp((ratio - 2) / 13, 0, 1) * 100`
       - ratio = peakValue / meanNoiseFloor
       - meanNoiseFloor = mean of |correlation[i]| for all i in search range where |i - peakIndex| > neighborhoodRadius (use 50 per RESEARCH.md)
       - For negative offsets, peakIndex wraps around fftSize; the neighborhood exclusion must account for this
       - If meanNoiseFloor is 0: return peakValue > 0 ? 100 : 0

    **gccPhat algorithm implementation (the core):**

    ```
    function gccPhat(reference, comparison, sampleRate, maxOffsetSeconds):
      // Validate minimum length
      if (reference.length < 1024 || comparison.length < 1024)
        throw new Error('Signals must be at least 1024 samples (minimum for meaningful correlation)')

      // 1. Apply Hann window (ALG-04)
      const refWindowed = applyHannWindow(reference)
      const compWindowed = applyHannWindow(comparison)

      // 2. Calculate FFT size: next power of 2 >= sum of lengths (ALG-04 zero-padding)
      const fftSize = nextPowerOf2(reference.length + comparison.length)
      const fft = new FFT(fftSize)

      // 3. Zero-pad into Float64Array for precision (Pitfall 7: use Float64 for intermediates)
      const refPadded = new Float64Array(fftSize)
      refPadded.set(refWindowed)
      const compPadded = new Float64Array(fftSize)
      compPadded.set(compWindowed)

      // 4. Allocate output buffers as Float64Array (not fft.createComplexArray which returns Array)
      // Interleaved complex format: [re0, im0, re1, im1, ...]
      const refSpectrum = new Float64Array(fftSize * 2)
      const compSpectrum = new Float64Array(fftSize * 2)

      // 5. FFT both signals (ALG-01: frequency-domain cross-correlation)
      fft.realTransform(refSpectrum, refPadded)
      fft.completeSpectrum(refSpectrum)   // CRITICAL: Pitfall 2 - must fill right half
      fft.realTransform(compSpectrum, compPadded)
      fft.completeSpectrum(compSpectrum)

      // 6. Cross-power spectrum with phase transform (ALG-01: GCC-PHAT)
      // G(f) = FFT(ref) * conj(FFT(comp))
      // W(f) = G(f) / |G(f)|  -- phase transform normalizes magnitude (ALG-02: robust to freq response)
      const crossSpectrum = new Float64Array(fftSize * 2)
      const EPSILON = 1e-10  // Pitfall 3: prevent division by zero
      for (let i = 0; i < fftSize; i++) {
        const refRe = refSpectrum[2*i]
        const refIm = refSpectrum[2*i + 1]
        const compRe = compSpectrum[2*i]
        const compIm = compSpectrum[2*i + 1]

        // Cross-power: ref * conj(comp)
        const crossRe = refRe * compRe + refIm * compIm
        const crossIm = refIm * compRe - refRe * compIm

        // Phase transform: normalize by magnitude
        const magnitude = Math.sqrt(crossRe * crossRe + crossIm * crossIm)
        if (magnitude > EPSILON) {
          crossSpectrum[2*i] = crossRe / magnitude
          crossSpectrum[2*i + 1] = crossIm / magnitude
        } else {
          crossSpectrum[2*i] = 0
          crossSpectrum[2*i + 1] = 0
        }
      }

      // 7. IFFT to get GCC-PHAT correlation
      const corrComplex = new Float64Array(fftSize * 2)
      fft.inverseTransform(corrComplex, crossSpectrum)

      // Extract real parts into correlation array
      const correlation = new Float64Array(fftSize)
      for (let i = 0; i < fftSize; i++) {
        correlation[i] = corrComplex[2*i]
      }

      // 8. Find peak within plausible offset range (ALG-05: parabolic interpolation)
      const maxOffsetSamples = Math.min(
        Math.floor(maxOffsetSeconds * sampleRate),
        Math.floor(fftSize / 2) - 1
      )

      // Search positive offsets [0, maxOffsetSamples] and negative offsets [fftSize-maxOffsetSamples, fftSize)
      const { index: peakRefinedIndex, value: peakValue, rawIndex: peakRawIndex } =
        findPeakParabolic(correlation, maxOffsetSamples, fftSize)

      // 9. Compute confidence (CONF-01: peak-to-noise-floor ratio)
      const confidence = computeConfidence(correlation, peakRawIndex, peakValue, maxOffsetSamples, fftSize)

      // 10. Map circular index to signed offset
      let offsetSamples = peakRefinedIndex
      if (peakRefinedIndex > fftSize / 2) {
        offsetSamples = peakRefinedIndex - fftSize
      }

      return { offsetSamples, confidence }
    ```

    **Sign convention (Pitfall 6):** Positive offsetSamples means the comparison signal started LATER than the reference. This matches the existing SynAudio convention in audioSync.ts where `sampleOffset / SYNC_SAMPLE_RATE` gives offsetSeconds.
