       export interface WaveformPeaks {
         min: Float32Array;
         max: Float32Array;
         length: number;        // number of buckets
         sampleRate: number;    // original sample rate (16000)

Return the level whose bucket count is >= needed, or detail if all are too coarse. Fallback to detail for extreme zoom.

<task type="auto">
  <name>Task 2: Build stateless WaveformCanvas component</name>
  <files>src/components/WaveformCanvas.tsx</files>
  <action>
    Create src/components/WaveformCanvas.tsx -- a pure rendering component that draws on a canvas element. This component has NO interaction handlers and NO state. It receives data and draws.

    Props interface:
    ```typescript
    interface WaveformCanvasProps {
      peaks: WaveformPeaks;
      viewState: ViewState;
      syncOffsetSeconds: number;  // this track's offset
      isReference: boolean;
      width: number;              // CSS pixel width
      height: number;             // CSS pixel height (recommend 80)
    }
    ```

    Implementation details:

    1. **Canvas setup with devicePixelRatio:** Use a useRef for the canvas element. In a useEffect, set canvas.width = width * dpr, canvas.height = height * dpr, canvas.style.width = `${width}px`, canvas.style.height = `${height}px`, then ctx.scale(dpr, dpr). Re-run on width/height change.

    2. **Waveform drawing:** In a useEffect triggered by peaks, viewState, width, height:
       - Calculate visible range: startBucket = floor(scrollOffset / peaks.samplesPerBucket), endBucket = min(startBucket + width, peaks.length)
       - Clear the canvas
       - Draw mirrored waveform: for each visible bucket, draw a vertical rect from (halfHeight - max * halfHeight) to (halfHeight - min * halfHeight). Color: `rgba(59, 130, 246, 0.6)` (blue-500 at 60% opacity). Use ctx.fillStyle + ctx.beginPath + ctx.rect + ctx.fill for batch rendering.
       - Draw center line: thin 1px line at halfHeight in gray-700 (`#374151`)

    3. **Sync marker:** Draw a vertical dashed line at the sync offset position:
       - Convert offsetSeconds to pixel x: `(offsetSeconds * sampleRate - scrollOffset) / samplesPerPixel`
       - If x is in visible range, draw with ctx.setLineDash([4, 4]), strokeStyle `#3b82f6` (blue-500), lineWidth 2
       - Draw a small label above: offset value in seconds (e.g., "+1.23s"). For reference track, draw "REF" label instead.

    4. **Cursor line:** If viewState.cursorTime is not null:
       - Convert cursorTime to pixel x: `(cursorTime * sampleRate - scrollOffset) / samplesPerPixel`
       - Draw thin vertical line in gray-400 (`#9ca3af`), lineWidth 1
       - Draw small time label at top of canvas

    5. **Trimmed region overlay:** If syncOffsetSeconds > 0 (non-reference), draw a semi-transparent overlay from x=0 to the offset marker position in `rgba(0, 0, 0, 0.3)` to indicate the trimmed portion.

    Return a `<canvas>` element with `ref={canvasRef}` and className for the container.

    Key anti-patterns to avoid (from research):
    - Do NOT use setState for any drawing -- all drawing goes through refs and useEffect
    - Do NOT re-create the canvas context on every render -- cache it
    - Use `requestAnimationFrame` is NOT needed here because this component does not handle events -- the parent will gate events via rAF before updating viewState
  </action>
